Add dual-language (Python + Bash) structured logging library to _shared/scripts/lib/.
ToolForgeLogger produces timestamped logs at _shared/logs/<tool>/ with section headers,
level-tagged lines (INFO/WARN/ERROR), and machine/agent/pid metadata in a preamble.
Both implementations emit identical log format for log_river harvest compatibility.
